I started this project in August of 2025. When I began it, I was already familiar with HTML, but not CSS, PHP, or JavaScript or how to use React in JavaScript. I was pretty good with Python so I hoped it wouldn't be too hard to migrate to JavaScript.

I began the project by creating the website. I watched a short tutorial series on HTML to refresh my memory on it and then laid out the basic setup of the website. I then watched a short tutorial on CSS because I had never worked with CSS before. I found CSS, like HTML, to be pretty easy and made the website look a little bit better.

Before we continue, I would like to give a quick shoutout to BroCode on YouTube. He has so many tutorial series on YouTube on just about any code language you can think of. I watched his videos to learn HTML, CSS, JavaScript and React, as well as Python and SQL when I was first learning those. You can check him out here. He's awesome.
